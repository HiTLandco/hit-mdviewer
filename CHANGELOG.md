# Changelog

## 0.1.0

- First release.
- Opens `.md` and `.markdown` files as a formatted page. Diff views stay text diffs.
- Automatic text direction per block, or forced right-to-left or left-to-right per file.
- Colours follow the editor theme.
- Text size, copy with formatting and printing through the browser.
- Offline, with the Vazirmatn font included.
